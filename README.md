# Flávio Júnior

### Sobre Mim

Estudante de Ciência da Computação na UFRN, com foco em Desenvolvimento Full-Stack, Engenharia de Software e Ciência de Dados.

Tenho interesse em construir soluções completas, bem estruturadas e orientadas a problemas reais, atuando desde a modelagem do banco de dados e desenvolvimento de APIs até a construção de interfaces funcionais e responsivas.

Atualmente, venho aprofundando meus conhecimentos em aplicações web, automações, sistemas de gestão, análise de dados e uso de Inteligência Artificial aplicada ao desenvolvimento de software.

---

### Principais Competências

#### Desenvolvimento Full-Stack

* **Back-End:** Desenvolvimento de APIs RESTful, regras de negócio, autenticação, integração com bancos de dados e organização de serviços.
* **Front-End:** Criação de interfaces modernas, responsivas e orientadas à experiência do usuário.
* **Bancos de Dados:** Modelagem, consultas, persistência e organização de dados em bancos relacionais e NoSQL.
* **Arquitetura de Software:** Organização de projetos, separação de responsabilidades, padronização de código e boas práticas de desenvolvimento.

#### Data Science & Inteligência Artificial

* Análise exploratória de dados e tratamento de datasets.
* Construção de pipelines de Extração, Transformação e Carga de dados.
* Aplicação de modelos de Machine Learning em problemas práticos.
* Uso de ferramentas de IA para produtividade, automação e apoio ao desenvolvimento.
